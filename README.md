# Life 新生涯

人工智能与新质生产力可视化课程作业。

## 打开

直接打开 `index.html`，无需安装依赖。主要背景、样式、脚本已内嵌；主题缩略图需要同目录的 `reference.png`。`highlights.html` 是可打印的网站亮点说明。

## 体验

- 生产效率：调整任务数量、重复步骤耗时减少比例，比较传统与协作耗时。
- 产业升级：切换四类行业，阅读数据、能力、应用与价值的流程。
- 新职业：切换设计师、数据分析师和教师，查看任务分工。
- 风险与治理：完成三个情境判断并查看解释。
- 数据来源：筛选研究数据和概念框架，访问原始资料。
- 浅深主题、手机菜单、键盘操作、返回顶部。

## 设计说明

按提供的原图保留工作室、城市与大光影。原图为主背景；局部清理图仅通过遮罩覆盖旧导航、分界线、按钮和文字区域，其他区域直接显示原图像素。只保留顶部一套导航。

本作品没有接入在线大模型；可视化是基于研究资料与明确假设的浏览器互动展示。

## 模型与来源

教学模型：每项任务包含 15 分钟重复步骤 + 5 分钟人工判断。工具只减少重复步骤，人工判断保留。行业和职业示例不代表企业实测数据。

研究来源见网站“数据来源”章节：NBER 2023 修订版、ILO/NASK 2025、国家发展改革委 2024、NIST AI RMF 1.0。
