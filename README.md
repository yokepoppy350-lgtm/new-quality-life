# Life 新生涯 · 人工智能与新质生产力

可视化导论课程作品。用真实研究、多视图联动实验、产业流程、职业任务矩阵与风险治理，解释 AI 如何转化为生产价值。

- 在线网站：https://yokepoppy350-lgtm.github.io/new-quality-life/
- GitHub 仓库：https://github.com/yokepoppy350-lgtm/new-quality-life
- 亮点说明：[可打印网页](highlights.html)

## 运行

下载源码压缩包并解压，直接打开 `index.html`。`hero-motion.svg` 和 `hero-still.svg` 必须与入口同目录。也可以使用任意静态服务器。页面交互可离线运行，外部资料链接需要网络。

## 核心设计

统一深色主题与一套顶部导航；可跳过、可重播的开场；保持原设计图场景和整体光影的动态 SVG 展景；可暂停动画并尊重系统减少动态偏好。移动端将文字与完整展景分开展示，避免遮挡。

真实研究比较图、三参数堆叠时间图、敏感性折线图、48 格热力图、100 格职业暴露图、职业任务矩阵、行业流程和治理关系图。点击热力图会联动参数、条形图和折线图。所有模型假设及局限公开列出。

## 源码与构建

提交压缩包的 `source/` 目录保留模板、样式、交互脚本、SVG 构建器和背景素材。修改后在根目录运行 `python build.py`。构建只使用 Python 标准库；浏览网站不需要 Python。WebP 为无损压缩，已逐像素验证与 PNG 一致。原图保留在 `source/assets/reference.png`。

## 资料与边界

- NBER 2023 年 11 月修订工作论文：5,179 名客服人员，平均提升14%，新手及较低技能群体提升34%；不混用2025期刊版口径。
- ILO/NASK 2025：全球约四分之一就业有一定潜在任务暴露，暴露不是失业。
- 国家发展改革委2024：新质生产力概念依据。
- NIST AI RMF1.0（2023）：治理贯穿识别、评估、管理，非固定顺序。

详见网页资料档案。互动实验是教学模型，行业与职业为机制示例，没有接入在线大模型或伪造企业成效。原图由作业参考提供，局部清理素材经图像编辑生成；其他视觉与图表使用原创HTML/CSS/SVG。
